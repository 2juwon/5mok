# 한판 오목

바로 하기: https://2juwon.github.io/5mok/

컴퓨터(초급·중급·고급)와 두는 오목. 외부 라이브러리 없이 HTML 한 파일로 돌아갑니다.

## 규칙
- **렌주룰**(기본): 흑만 3-3·4-4·장목(6목 이상) 금수, 백은 장목도 승
- **일반룰**: 흑·백 모두 3-3 금지, 4-4 허용, 장목은 승 아님
- **자유룰**: 금지 없음, 장목도 승
- **직접 정하기**: 3-3 금지(없음/흑만/모두), 4-4 금지(없음/흑만/모두), 흑 장목(승/무효/금수), 백 장목(승/무효)
- 판 15줄 / 19줄. 다섯을 만드는 수는 금수 모양이어도 승. 3-3은 '진짜 열린 3'(한 수 더 두면 열린 4가 되고 그 자리가 금수가 아닌 것)만 셈

## 컴퓨터
- 초급: 눈앞 점수 + 큰 흔들림. 4는 대개 막지만 열린 3은 자주 놓침
- 중급: 4·열린 4는 꼭 처리, 두 수 앞까지 읽음
- 고급: 연속 4(VCF)·3과 4로 몰아붙이기(VCT) 찾기, 상대의 그런 공격을 막는 수만 남기기, 알파베타 반복 심화(한 수 약 1.5초, 웹 워커에서 계산)

## 구조
- `src/engine.js` 규칙 엔진 `OM` (금수 판정, 승리, 무르기)
- `src/ai.js` 컴퓨터 `OMAI` (11칸 모양 표 59,049개 미리 계산 → 점수, 탐색)
- `src/ui.html` 화면
- `node build.js` → `index.html`(GitHub Pages용) · `dist/omok.html`(아티팩트용)

## 시험
- `node test/rules.test.js` 규칙·컴퓨터 시험
- `node test/sim.js [판 수] [고급 시간ms]` 컴퓨터끼리 대국
- `python3 test/browser.py [스크린샷 폴더]` 브라우저 자동 플레이(Playwright)
